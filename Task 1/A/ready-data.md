# Dataset Readiness

Variables that show if a dataset can be analysed and ideal order:
1. **File Format** - What is the file format? 
2. **Size** - What is the size of the dataset? How do tools perform when analysing the dataset? Number of rows and columns?
3. **Data Types** - What are th data types? Is it standardised across the dataset? Can you use excel/power query to check?
4. **Completeness** - Is the dataset complete? How does it compare to the brief?
5. **Data Cleaning** - If the data has been cleaned? What needs to be cleaned? What's the effect of it being clean/unclean? Is there any outliers?
   * Uncertainty on outliers means that you need to leave it but mention in the document; flag unusual values but do not delete
7. **Updated** - When it was last updated?

For each factor, **specifiy** where it is an explain its **effect** to the analysis.

<br>

Paragraph structure:
1. FIND - What did you notice?
2. EFFECT - Why could it matter?
3. ACTION - What should happen next?
4. BENEFIT - How will this improve the analysis?

<br>
Also, an overall judgment based on these factors as a conclusion. The three dataset statuses are; Good, Good but needs cleaning/formatting and Bad.
