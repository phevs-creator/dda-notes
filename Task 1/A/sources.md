Use [StatCalcPro](https://statcalc.pro/) to compare datasets and find the originality of the dataset.

## Investigation

There are multiple categories of metadata that need to be analysed for a trusted dataset:
* Owner + Author
* Licensing
* Data collection/measuring methods
* Data cleaning
* Date published/last date updated (More than three years is a risk unless updated frequently)
<br>

Direct and Indirect identifiers:
* Direct - like email, phone, account, ID...
* Indirect - like age, dates, location, job...

Explain why/why not identifiers are removed/kept.

<br>

Risk Mitigation:
* Establish lawful purposes
* Minimise fields
* Restrict access
* Count of data (a data source might have more records to another dataset that is being compared)
* Version control

<br>

Licence information:
* Copyright
* Rights
* Cost
* Public use
* Commercial use
