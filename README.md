# Digital Data Analytics
This is to collect notes and code related to the T-Level Digital Data Analytics course. The specification for this course can be found on [Pearson's website](https://qualifications.pearson.com/content/dam/pdf/TLevels/digital-data-analytics/2025/specification-and-sample-assessment-materials/digital-dda-specification.pdf). My notes are separated into each unit and then the subsections as mentioned in the content header below.

## Content
* Task 1 (Sourcing Data and making Model) takes 20 hours (42 mks)
  - A - Research + Report
  - B - Visualisation
  - C - Data Dictionary
* Task 2 (Dashboard Creation) takes 15 hours
* Task 3 (Evaluation) takes 12.5 hours
