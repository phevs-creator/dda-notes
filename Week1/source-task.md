## Client Brief: Population Data Analysis Model for PopInsights
### Background
The data analysis company that you work for has secured a new contract to develop a data model for PopInsights. PopInsights specialises in locating, analysing, and interpreting population data from various national and international sources. The organisation converts raw population data into meaningful information that supports governments, policymakers, businesses, healthcare providers, and educational institutions in making informed decisions about resource allocation, service planning, and future development.
<br>

PopInsights is developing a data model to analyse population trends and provide insights that can support strategic planning and decision-making. The data model should focus on three key factors:
* Population characteristics (e.g., age, gender)
* Geographical location (e.g., country, region, city, district)
* Time period (e.g., census year, annual population estimates, quarterly updates)
<br>

### Project Requirements
The client (PopInsights) would like you to locate suitable datasets containing this information and then design a data model that generates useful insights into population trends and demographic changes.
The selected datasets must include:
* Population characteristics (age, gender, etc.)
* Geographical information (country, region, city, district, etc.)
* Time-related information (census dates, reporting years, historical periods, etc.)
<br>

### Task
Locate two publicly available and reliable population datasets that can be used to generate demographic insights.
Once you have located two datasets, you should produce a written report with suitable screenshots, justifying the suitability of each dataset.
<br>
